오르골 꿈나라 수비대 — 화풍 시안 5종

실제 게임 화면 구성(상단 하트·별빛 / 중앙 6칸 회전판·곰·병정·토끼 / 하단 카드 3장+자장가) 기준 세로 시안입니다. 이미지를 누르면 원본 크기로 열립니다.

1. 매트 3D 2. 벡터 카툰 3. 동화책 과슈 4. 펠트·원목 5. 토이+외곽선

1번 · 매트 3D 클레이·피규어풍

난이도 중~상

무광 점토·바이닐 피규어와 나무·황동 오르골 질감, 포근한 미니어처 조명 스타일.

프리렌더 2D 이미지로 구우면 Godot 2D에서도 가볍게 구동 가능. 스토어 첫인상 흡입력 최상.

2번 · 굵은 외곽선 파스텔 벡터 카툰풍

난이도 하(가장 빠름)

따뜻한 코코아·진남색 둥근 외곽선과 파스텔 채색의 경쾌한 2D 카툰 스타일.

작은 폰 화면 가독성 최상, 파츠 애니메이션·이펙트 제작 속도가 가장 빠름.

3번 · 동화책 과슈 & 색연필 일러스트풍

난이도 중

종이 질감 위에 매트한 과슈 물감과 색연필 터치, 앤티크 황동 태엽을 살린 잠자리 그림책 감성.

유아용 클립아트처럼 보이지 않는 서정적인 인디 게임 인상에 강점.

4번 · 양모 펠트 & 원목 공예 디오라마풍

난이도 중~상

바느질 스티치가 보이는 펠트 인형, 깎아 만든 나무 원판, 털실 먼지 괴물, 천 가격표 카드.

손으로 만질 듯한 아기자기함이 특징. 하단 '천 태그 카드' 디자인만 다른 시안에 섞어도 좋음.

5번 · 매트 토이 볼륨 + 카툰 외곽선

난이도 중(추천 타협점)

1번의 통통한 매트 입체감·조명과 2번의 깔끔한 브라운 외곽선을 절충한 2.5D 토이박스 스타일.

"2D는 너무 납작하고 풀 3D는 무겁다" 싶을 때 입체감과 선명도를 동시에 잡는 실용적 시안.

선택 팁: 단일 번호(1~5번)로 골라주셔도 되고, "캐릭터·외곽선은 5번인데 오르골 나무 질감·하단 카드 태그는 4번처럼" 같이 조합해서 말씀해 주셔도 됩니다.
